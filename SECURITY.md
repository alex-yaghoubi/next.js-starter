# Security policy

## Supported code

The current published npm release and the development branch can differ.
Check the npm version badge and the project changelog when assessing
whether a fix has been released.

## Report a vulnerability privately

If you find a vulnerability or accidentally exposed credentials, **do not**
create a public GitHub issue containing exploit details or secrets.
Email **contact@alexyaghoubi.dev** with the subject
**Security: create-nextjs-standard-app** and include:

- An affected version or commit,
- A concise reproduction and the potential impact,
- Any relevant logs with credentials and personal data redacted.

Please allow reasonable time for investigation and remediation before
public disclosure. No response-time or bounty commitment is implied.

## Deployment reminder

The generated authentication and appointment routes are examples, not
production-ready implementations. Review authorization, session handling,
API integrations, and secret management before use with real users.
